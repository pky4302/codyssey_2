# codyssey_2
코디세이 2주 과제

```
<프로젝트 개요>

1.사용자가 퀴즈를 등록하여 퀴즈를 풀 수 있고 퀴즈 결과를 볼 수 있도록 구현한 프로그램입니다.
2.등록된 퀴즈, 퀴즈 결과는 파일에 저장하고 파일에서 불러와 이들을 조회할 수 있는 프로그램입니다.
3.퀴즈 등록, 퀴즈 풀기 등 입력 행위 시 오류가 발생할 수 있는 예외 상황을 고려한 프로그램입니다.
```
```
<퀴즈 주제 선정 이유>
퀴즈게임은 파이썬 명령어에 관한 문제를 제시합니다. 문제 점수는 한 문제 당 1점이며 힌트를 사용하여 맞추었을 시
0.5점 차감, 힌트 미사용 시 1점 획득을 하는 방식으로 퀴즈게임이 진행됩니다.
```
```
<실행방법>

터미널에서 codyssey_2 폴더로 이동 후 파이썬 main을 실행합니다.
실행 후 퀴즈 목록이 나옵니다. 아래 "메뉴 선택:" 에서 원하는 항목 번호를 입력하여 서비스를 진행할 수 있습니다.

1.퀴즈풀기

  메인 메뉴에서 1을 입력합니다.

  원하는 퀴즈 주제를 선택합니다.

  출제할 문제 수를 입력합니다.

  문제가 출력되면 정답 번호 1~4를 입력합니다.

  힌트를 사용하려면 h를 입력하고, 사용하지 않으려면 Enter를 누릅니다.

  모든 문제를 풀면 최종 점수와 정답률이 출력됩니다.

2.퀴즈추가

  메인 메뉴에서 2를 입력합니다.

  등록할 문제 내용을 입력합니다.

  선택지 4개를 차례대로 입력합니다.
  
  정답 번호 1~4를 입력합니다.

  힌트 내용을 입력합니다.

  등록이 완료되면 퀴즈가 자동 저장됩니다.

3.퀴즈목록

  메인 메뉴에서 3을 입력하면 현재 등록된 퀴즈 목록을 확인할 수 있습니다.

4.점수확인:
메인 메뉴에서 4를 입력하면 다음을 확인할 수 있습니다.

  최근점수
  달성한 최고 점수
  게임 날짜 및 시간
  푼 문제 수
  정답 수와 오답 수
  획득 점수
  정답률

5.퀴즈삭제:

  메인 메뉴에서 5를 입력합니다.

  삭제할 퀴즈의 목록 번호를 입력합니다.

  선택한 퀴즈가 삭제되고 변경 사항이 자동 저장됩니다.

6.종료:

  퀴즈, 최고 점수 및 게임 기록은 프로젝트 폴더의 state.json 파일에 저장됩니다. 프로그램을 다시 실행해도 기존 데이터를 불러옵니다.

```
```
<기능목록>

quiz_list() 기본 퀴즈 데이터

Quiz 클래스의 메서드
  __init__()	문제, 선택지, 정답, 힌트를 초기화
  show_question()	문제와 4개의 선택지를 화면에 출력
  check_answer()	사용자가 입력한 답과 실제 정답을 비교
  show_hint()	해당 퀴즈의 힌트를 출력

QuizGame 클래스의 메서드
  __init__()	게임에 필요한 변수 초기화 및 저장 데이터 불러오기
  start()	메인 메뉴를 출력하고 사용자 선택에 따라 기능 실행
  get_menu_choice()	메뉴 입력값 검증
  play_quiz()	퀴즈 진행, 정답 확인 및 점수 계산
  get_question_count()	사용자가 풀 문제 개수 입력 및 검증
  get_answer()	퀴즈 정답 입력 및 입력값 검증
  add_quiz()	새로운 퀴즈 등록
  list_quizzes()	등록된 퀴즈 목록 출력
  delete_quiz()	선택한 퀴즈 삭제
  show_score()	현재 점수와 최고 점수 출력
  show_history()	전체 게임 기록 출력
  save_state()	퀴즈, 최고 점수, 게임 기록을 JSON 파일에 저장
  load_state()	JSON 파일에서 퀴즈와 점수 데이터를 불러오기


기본 퀴즈 데이터가 필요함으로 quiz_list라는 기본 퀴즈를 Quiz 객체를 담은 리스트로 만들어 프로그램 시작 시 항상 존재하도록 만듭니다.

Quiz 클래스는 퀴즈 문제와 관련된 속성을 담고 있습니다. Quiz 객체는 퀴즈의 문제, 선택지, 답, 힌트 속성을 갖추고 있습니다.
Quiz 객체에 문제를 보여주는 메서드 show_question(), 사용자 입력과 실제 정답을 비교하는 메서드 check_answer(), 힌트를 보여주는 메서드 show_hint()가 있으며, 해당 메서드는 QuizGame 클래스에서 활용되는 Quiz 객체에 인스터스 메서드로 활용됩니다. 


QuizGame 클래스는 게임 진행과 관련된 속성을 지닙니다. 파일내부에서 생성자로 값을 넣는 과정 없기 때문에 게임을 처음 시작했을 때 점수와 최고점수 그리고 점수내역에 대해 초기화 값을 지정합니다. 클래스 초기화에 불러오기 함수를 통하여 최고점수 그리고 점수내역을 프로그램 시작 시 불러온 데이터로 갱신합니다.

게임 시작은 main에서 QuizGame 객체를 생성 후 인스턴스 메서드인 start()를 호출하여 시작합니다.
start()는 show_menu()를 보여주고 get_menu_choice()에서 메뉴 번호를 검증입력 받아 이를 변수에 지정 후 while반복문 속 조건문을 통해
목록의 서비스를 담당하는 메서드를 호출하도록합니다. start()의 while 반복문을 오류가 발생할 수 있는 영역으로 가정하여 try로 묶고 except로 오류를 처리합니다. 프로그램 실행 도중 Ctrl + c 또는 입력을 받을 수 없는 오류가 발생하면 프로그램을 안전하게 종료할 수 있습니다.

퀴즈 추가 항목을 선택하면 add_quiz()를 호출합니다. 문제를 입력받고, 선택지를 리스트로 받고, 답을 입력받을 때는 get_answer()에서 입력검사를 받아 답을 입력받고 마지막으로 힌트를 입력받습니다. 받은 입력은 값을 각 변수에 담았다가 Quiz 객체를 생성자로 변수의 값을 받아 생성합니다. import를 통해 quiz_list를 불러와 Quiz 객체를 .append 해주면 퀴즈가 추가됩니다.

퀴즈를 추가했다면 퀴즈 목록에서 1번을 입력받아 play_quiz()를 호출합니다. 퀴즈는 quiz_list에서 받아오고 만약 리스트가 비어있다면 return합니다.
get_question_count()를 호출하여 몇 문제를 풀건지 입력받는 동시에 입력검증을 받습니다. quiz_list와 풀 문제 수를 매개변수로 받아 random.sample()를 호출하여 문제 순서를 무작위로 바꾼 리스트로 만들고 변수에 담아 반복문으로 문제를 하나씩 출력합니다.
힌트는 "h"를 눌렀을 때 볼 수 있도록 조건문이 이용되었고 힌트를 보았을 때 차감되는 점수 관리는 반복문 안 used_hint 의 bool값으로 관리합니다.
get_answer()를 호출하여 값형식 검증과 정답 입력을 받고 Quiz의 인스턴스 메서드 check_answer()를 호출하여 입력받은 답을 확인합니다.
used_hint가 False일 때 정답을 맞추었으면 1점 획득, True일 때는 0.5점을 받도록 점수 관리를 합니다.
문제를 다 풀면 전체문제, 정답, 오답, 획득점수, 정답률에 대해 변수에 저장된 값을 통해 계산하여 보여주며 "점수확인" 목록에서 점수에 대한 기록을 보여주기 위해 함수 초기화 시 생성되는 score_history 리스트에 해당 내용을 추가합니다.
 
퀴즈 추가와 퀴즈를 푼 결과 모두 save_state() 호출을 통해 json에 저장됩니다. 추가된 퀴즈, 최고점수, 점수기록을 딕셔너리로 정리 후 json에 저장합니다. 만약 퀴즈 추가를 하지 않고 퀴즈만 풀었다면 퀴즈 목록은 기존 목록 그대로 덮어씀으로 빈 리스트가 되지 않습니다.

json에서 불러오는 데이터는 프로그램 실행 시 한번 실행되는 init() 호출에서 시작합니다. __init__에 load_state() 호출을 통해 그 동안 수정된 quiz_list를 불러옵니다. load_state()가 호출되면 먼저 파일의 존재를 찾고 없으면 return하여 불러오기를 건너띄고 기본 quiz_list의 문제를 제공합니다. try except로 전체 디셔너리에서 부터 시작해서 문제, 선택지, 정답, 점수기록 등 오류 예외가 발생할 수 있는 부분을 각각 rasie로 지정한 다음
최종 except에서 예외 처리 시 파일 손상의 문구와 raise에 지정한 세부 오류 문구를 둘 다 확인할 수 있다.

퀴즈 삭제는 불러온 quiz_list에서 list의 인덱스를 입력받아 해당 리스트의 요소를 제거하는 방식으로 이루어집니다.

퀴즈 조회는 불러온 quiz_list를 반복문으로 하나씩 꺼내어 형식을 갖춘 모습으로 만든 후 출력합니다.

get_menu_choice(), get_answer(), get_question_count() 모두 입력값을 검증하고 입력을 받는 함수입니다.
모두 공통적으로 입력을 받고 변수에 담는 코드에 try except로 묶어 오류 발생 시 안전하게 처리합니다.
```
